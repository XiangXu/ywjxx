# 🏗️ 系统设计总览 System Design Overview

> 系统设计的学习笔记，从计算机基础到分布式系统 ✍️
> Notes on designing systems, from computer fundamentals to distributed systems.

## 📚 笔记 Notes
- 🖥️ [[Computer Architecture]]: 磁盘、内存、CPU、缓存、存储层级和摩尔定律 Disk, RAM, CPU, caches, the memory hierarchy, and Moore's Law
- 🏛️ [[Application Architecture]]: 服务器、客户端、垂直与水平扩展、负载均衡、日志、指标和告警 Servers, clients, vertical vs horizontal scaling, load balancers, logs, metrics, and alerts
- 📐 [[Design Requirements]]: 数据的移动、存储与转换；可用性和几个 9、SLA/SLO、可靠性、冗余、吞吐量与延迟 Moving, storing, and transforming data; availability and the nines, SLA/SLO, reliability, redundancy, throughput, and latency
- 🌐 [[Networking Basics|网络基础 Networking Basics]]: IP 地址（IPv4/IPv6）、数据包、IP 与 TCP、网络分层、公网与私网、静态与动态 IP、端口 IP addresses (IPv4/IPv6), packets, IP and TCP, network layers, public vs private, static vs dynamic IPs, and ports
- 🚚 [[TCP and UDP|TCP 与 UDP TCP and UDP]]: 三次握手、确认与重传、TCP 的代价、UDP 的使用场景、QUIC 和两者对比 The three-way handshake, ACKs and retransmission, what TCP costs, when to use UDP, QUIC, and a side-by-side comparison
